# AML Crypto Compliance

A reproducible study of illicit Bitcoin transaction detection using the
Elliptic transaction graph dataset.

## Setup

1. Create and activate a Python 3.12 virtual environment.
2. Run `python -m pip install -r requirements.txt`.
3. Follow `docs/dataset.md` to obtain the dataset.
4. Start Jupyter with `jupyter lab`.
5. Open `notebooks/main.ipynb` and select the project kernel.

The raw dataset and generated artifacts are intentionally excluded from Git.
